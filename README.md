# PlaneWar
This is a simple game make in C++, Cmake, GLFW and Imgui.

## Our Game design like this:
### UI:
```
_____________
|           |
| PlaneWar  |
| > Start < |
|  Settings |
|   Exit    |
|___________|
```
## How to play:
First, select what mode will you play:
- Multiplayer ( Player 1 use WASD, Space to shoot Bullets. Player 2 arrows, Enter to shoot Bullets )
- Singleplayer ( Player use WASD, Space to shoot Bullets )
- PVP ( Player 1 vs Player 2, control features are the same )
## Levels ( Multiplayer and Singleplayer are the same )
- Level 1: Players fly through loads of rocks
- Level 2: Players fight against with enemies.
- Level 3: Players fight with the BOSS, BOSS will shoot extremely powerful Xray.

- TIP: Do not touch the Xray!

## PVP:
Player 1 at the bottom of the screen, 
Player 2 at the top of the screen. 
Players can shoot each other, and the first player to lose all health loses the game.
